# PolarWatch Web Monitor v2.1.0

First standalone, free/open-source release of the redesigned PolarLabs website monitor.

- Dark navy / turquoise PolarLabs interface and neon PolarWatch icon
- Online/offline status, HTTP response time, average latency, TLS expiry
- Expert mode: DNS resolution, IPs, TTFB, redirect, TLS and cipher details, security header presence
- Copy a technical report to clipboard
- Manual checks and optional periodic checks at 1, 5, 15, 30 or 60-minute intervals
- Stores only selected names and URLs in a per-user JSON file; no SQLite/database
- No account, licensing, backend, mining, wallet or cloud requirement
- Builds automatically on Windows x64 / ARM64 and Linux x64 / ARM64

> Executables are not digitally signed. Linux requires a graphical desktop and dependencies compatible with the build environment. This software performs periodic *point-in-time checks*, not guaranteed continuous monitoring.
